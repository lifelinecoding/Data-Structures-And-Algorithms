# Stacks

A stack follows last-in, first-out order. This folder compares array and linked-list implementations and includes expression-conversion examples that use stack operations.

## Suggested learning sequence

1. [Array implementation](./Implememtation%20Using%20Array/README.md) — learn the core push and pop behavior.
2. [Linked-list implementation](./Implementation%20Using%20Linked%20List/README.md) — compare dynamic storage.
3. [Expression conversion](./Implememtation%20Using%20Array/Expression%20Conversion/README.md) — apply a stack to infix, postfix, and prefix expressions.

## Key ideas

- Push and pop operate at the same end, called the top.
- Track empty and full conditions explicitly for an array-based stack.
- Expression conversion depends on operator precedence, associativity, and correct handling of parentheses.
