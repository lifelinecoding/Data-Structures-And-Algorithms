# Trees

Trees organize values hierarchically. This folder introduces array and linked representations, then develops binary trees, binary-search trees, and AVL trees.

## Suggested learning sequence

1. [Array implementation](./Implementation%20Using%20Array/README.md) — study index-based storage.
2. [Linked implementation](./Linked%20Implementation/README.md) — move to nodes connected by pointers.
3. [Binary tree](./Linked%20Implementation/Binary%20Tree/README.md) — establish the shared linked binary-tree structure and traversal material.
4. [Binary search tree](./Linked%20Implementation/Binary%20Tree/Binary%20Search%20Tree/README.md) — use an ordering invariant for search and updates.
5. [AVL tree](./Linked%20Implementation/Binary%20Tree/AVL%20Tree/README.md) — study balancing to keep height controlled.

## Key ideas

- A node's position and links define parent-child relationships.
- Binary-tree traversals visit nodes in different orders.
- A binary search tree relies on an ordering invariant; an AVL tree adds a balance invariant and rotations.
- Trace pointer updates and boundary cases when inserting or deleting nodes.
