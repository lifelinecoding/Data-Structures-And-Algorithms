# Prerequisites

These examples introduce C concepts that recur throughout the data-structure folders. Work through them before studying implementations that allocate and link nodes.

## Suggested learning sequence

1. [`Structures.c`](./Structures.c) — declare and use a C structure.
2. [`NestedStructures.c`](./NestedStructures.c) — place one structure inside another.
3. [`ArrayOfStructuresObjects.c`](./ArrayOfStructuresObjects.c) — store multiple structure values in an array.
4. [`DynamicMemoryAllocation.c`](./DynamicMemoryAllocation.c) — allocate and release memory at runtime.
5. [`CallStackVisual.c`](./CallStackVisual.c) — use a visualization example to think about function calls and stack frames.

## Key ideas

- Structures group related fields into one type.
- Arrays of structures combine record-like values with indexed storage.
- Dynamically allocated memory has a lifetime that the program must manage explicitly.
- Read each program's declarations and input assumptions before compiling and running it.
