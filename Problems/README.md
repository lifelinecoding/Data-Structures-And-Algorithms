# Practice problems

This folder collects small exercises that apply data structures and algorithmic reasoning. Try each problem yourself before reading or running its implementation.

## Suggested learning sequence

1. [`ElementCountProblem.c`](./ElementCountProblem.c) — count occurrences or elements in a collection.
2. [`CharacterFrequency.c`](./CharacterFrequency.c) — count characters in input text.
3. [`OddElementOccurence.c`](./OddElementOccurence.c) — reason about values that occur an odd number of times.
4. [`ParanthesisMatching.c`](./ParanthesisMatching.c) — check balanced delimiters, a natural stack application.
5. [`LinkedListPalindrome.c`](./LinkedListPalindrome.c) — compare values in a linked list from opposite directions.
6. [`IsBinarySearchTree.c`](./IsBinarySearchTree.c) — check whether a tree satisfies binary-search-tree ordering.

## How to practice

- Write down input constraints and expected output before coding.
- Test empty, smallest valid, duplicate, and boundary cases.
- Identify which data structure or invariant makes the solution work.
- Filenames reflect the checked-in spelling; `OddElementOccurence.c` and `ParanthesisMatching.c` retain their existing names.
