# Hashing

Hashing maps keys to table positions using a hash function. A complete implementation should also explain how it handles collisions and table growth.

## Folder status

This folder is currently empty; no hashing implementation is checked in yet.

## Suggested learning sequence

When examples are added, study them in this order:

1. Hash function and key-to-index mapping.
2. Collision handling, such as chaining or open addressing.
3. Lookup, insertion, and deletion behavior.
4. Load factor and resizing, including the effect on expected performance.

For now, continue with another topic from the [repository guide](../README.md).
