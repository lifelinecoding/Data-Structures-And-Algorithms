# Array-based stack

[`Implementation.c`](./Implementation.c) demonstrates a stack stored in an array. The folder also contains expression-conversion programs that build on stack behavior.

## Suggested learning sequence

1. Read `Implementation.c` and identify the top index and the push, pop, and peek behavior.
2. Trace pushes and pops until the stack is empty and, if bounded, full.
3. Continue to [Expression Conversion](./Expression%20Conversion/README.md) after the stack operations are clear.

## Key ideas

- The most recently pushed value is the first one popped.
- Array stacks have a capacity; guard against overflow and underflow.
- The folder name retains the existing spelling `Implememtation`.
